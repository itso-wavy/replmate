### 알람 형태

1. 대시보드
   ◈ 대시보드 경고 배너
   페이지 상단에 사용자 조치가 필요한 경고 배너를 노출
   경고 배너는 생성일자 기준으로 최신 순 정렬되며, 최대 3개까지 표시(결제 실패 경고 포함 최대 3개)
   결제 실패 관련 경고가 존재할 경우 생성일자와 관계없이 최상단에 고정 노출
   경고 조건이 해소되면 해당 경고 배너는 자동으로 제거

■ 오류배너\_결제 실패

- 정기 결제에 실패했습니다. D-2 후 무료 플랜으로 전환됩니다.
  원활한 서비스 이용을 위해 결제 정보를 확인해 주세요.
- 해당 페이지로 이동(구독 관리 페이지로 이동)

■ 경고배너\_쇼핑몰 인증 반려

- 쇼핑몰 관리자 인증이 반려되었습니다.
- 해당 페이지로 이동(쇼핑몰 연동 페이지로 이동)

■ 경고배너*다운그레이드*쇼핑몰 수 초과

- 구독 플랜 변경으로 쇼핑몰 수 조정이 필요합니다.
- 해당 페이지로 이동(쇼핑몰 연동 페이지로 이동)

■ 경고배너*다운그레이드*상품 수 초과

- 구독 플랜 변경으로 상품 수 조정이 필요합니다.
- 해당 페이지로 이동(상품 관리 페이지로 이동)

2. 쇼핑몰 연동
   ◈ 플랜 변경으로 쇼핑몰 조정이 필요한 경우 - 플랜 다운그레이드로 인해 현재 연동된 쇼핑몰 수가 변경될 한도를 초과하였으며, 아직 유지할 대상을 확정하지 않은 경우 노출
   ■ 조정 필요 경고 배너

- 구독 플랜 변경으로 쇼핑몰 조정이 필요합니다.
- 2025.01.01부터 무료 플랜(쇼핑몰 최대 n개 · 상품 최대 nn개)이 적용됩니다.
  현재 쇼핑몰 m개, 상품 mm개가 등록되어 있어 조정이 필요합니다. 기한 내 조정하지 않으실 경우, 최근 등록된 순서대로 자동 비활성화 처리됩니다.

◈ 플랜 변경이 예정된 경우(쇼핑몰 조정 완료)
■ 조정 예정 안내 배너(유지할 쇼핑몰 선택을 완료하였으나, 아직 플랜 변경일이 도래하지 않은 경우 노출)

- 구독 플랜 변경으로 쇼핑몰이 조정될 예정입니다.
- 2025.01.01부터 무료 플랜(쇼핑몰 최대 n개 · 상품 최대 nn개)이 적용됩니다.
