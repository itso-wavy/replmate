### 기능 요구사항

0.  API 개발되었는지 확인 필요. 아직 안 되어 있을 수 있음

1.  ■ 노출 조건
    - 구독 상태: 유료(ACTIVE)/변경예정(DOWNGRADE_SCHEDULED) 중 1개
    - [결제 정보 변경] 버튼 클릭 시

2.  ■ 필드: 카드 번호\*
    - 숫자만 입력 사능
    - 16자 미만 입력 시 에러(메시지: '숫자 16자리를 입력해 주세요')
    - 16자 초과 입력 시 입력 제한
    - 4자리마다 자동 띄어쓰기 적용

3.  ■ 필드: 유효기간 (MM/YY)\*
    - 숫자만 입력 가능
    - 4자 미만 입력 시 에러(메시지: '숫자 4자리를 입력해 주세요')
    - 4자 초과 입력 시 입력 제한
    - 월(01~12), 연도(현재 연도 이상) 유효성 실시간 체크(메시지: '???')

4.  ■ 필드: CVC\*
    - 숫자만 입력 가능
    - 3자 미만 입력 시 에러(메시지: '숫자 3자리 이상 입력해 주세요')
    - 4자 초과 입력 시 입력 제한
    - 입력 시 마스킹(`***`) 처리

5.  ■ 필드: 카드 소유주 이름\*
    - 영문만 입력 가능
    - 입력시 자동으로 대문자로 변환
    - 2자 미만 입력 시 에러(메시지: '2자 이상 입력해 주세요' )
    - 50자 초과 입력 시 입력 제한

6.  ■ [변경하기] 버튼
    - 모든 필수 항목이 유효성 검증을 통과 시 활성화
    - 필수 항목 미입력 상태로 버튼 클릭 시 에러 토스트 노출
      - '필수 항목을 모두 입력해 주세요.'(필수 항목이 누락된 상태로 [변경하기] 버튼 클릭한 경우)
    - 유효성 검증 미통과 상태로 버튼 클릭 시 에러 토스트 노출
      - 'n자 이상 입력해 주세요.'(최소 입력 기준에 부합하지 않는 경우)
      - '최대 n자까지 입력 가능합니다.'(최대 입력 기준에 부합하지 않는 경우)
      - '허용되지 않은 문자가 포함되어 있습니다.'(허용되지 않은 문자를 입력한 경우)
    - 클릭 시 처리:
      - 클릭 시 입력 정보를 PG사로 전송하여 유효한 카드인지 확인 및 신규 빌링키 발급
      - 신규 빌링키를 해당 회원의 '차기 결제 수단'으로 DB에 저장(갱신)
      - ▣ 모달 닫힘 및 안내 토스트 노출
        - `결제 정보 변경이 완료되었습니다.\n다음 결제일부터 적용됩니다.`(성공 시)
        - `일시적인 오류로 변경에 실패했습니다. 잠시 후 다시 시도해주세요.`(실패 시)
