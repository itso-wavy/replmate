### 기능 요구사항

1. 별칭 등록 영역
   1. 한글, 영문, 숫자, 하이픈(-), 언더스코어(\_), 괄호, 공백만 입력 가능
   2. 그 외 문자 키 입력 시 화면에 입력되지 않음
   3. 입력 후 포커스 이탈(Focus Out) 시 글자 수 검증
   4. 2자 미만 입력 시 입력 필드 테두리를 붉은색으로 변경
   5. 2자 미만 입력한 경우: 보더 빨간색만 뜸
   6. 2자 미만 입력한 경우 에러 메시지 보이도록 하기('2자 이상 입력해 주세요')
   7. Max: 15자까지만 입력되도록 하기
2. 플랫폼 선택 영역
   1. 네이버 스마트스토어 / 브랜드스토어 중 선택(추후 쿠팡, 자사몰 등 추가 예정)
   2. 미선택시 에러 메시지 노출('플랫폼을 선택해 주세요')
   3. 드롭다운 클릭 후 값 입력하지 않고 이탈시 에러(일반 input처럼)
3. URL 등록 영역
   1. 영문, 숫자, 하이픈(-), 언더스코어(\_)만 입력 가능
   2. 그 외 문자 키 입력 시 화면에 입력되지 않음
   3. 입력 안 했을 때 에러 메시지 노출('URL을 입력해 주세요')
   4. 5자 미만 입력 시 에러 메시지 노출('5자 이상 입력해 주세요')
   5. Max: 100자까지만 입력되도록 하기
   6. 플랫폼 미선택 상태에서 URL 필드 focus out 시 에러 메시지 노출('플랫폼을 먼저 선택해 주세요') — URL 빈값 포함
   7. URL 필드 에러 메시지 우선순위: 플랫폼 미선택 > 빈값 > 길이 부족 (동시 충족 시 최우선만 노출)
   8. URL 필드 에러 메시지 노출 시점: focus out
4. URL 중복확인 영역
   1. URL 입력 필드에 유효한 값이 입력되고, 플랫폼 선택 값이 있을 때 [중복 확인] 버튼 활성화
   2. 클릭 시 입력된 URL의 시스템 내 중복 여부 검증
   3. 검증 결과를 입력창 하단 텍스트로 노출. URL 필드 에러메시지 영역을 대체함
      1. 가능: 사용 가능한 URL 입니다
      2. 불가능: 이미 등록된 URL 입니다
   4. 가능일 경우 버튼 텍스트가 [확인 완료]로 변경되며 클릭 불가 상태됨
   4-1. 불가능일 경우 버튼은 [중복 확인] 유지 + 활성 상태. URL 수정 시 결과 메시지 초기화
   5. 중복 확인 완료 후 URL를 수정할 경우, 확인 상태를 초기화, 검증 결과 메시지 초기화
   6. 중복 확인 여부와 무관하게 [플랫폼 선택 드롭다운]의 값을 변경시 확인 상태 초기화 (URL 입력값은 유지)
5. 증빙 파일 첨부 영역
   1. 영역 클릭 시 파일 탐색기 호출 또는 드래그 앤 드롭으로 파일 첨부 가능
   2. JPG/PNG/PDF, 건당 5MB 이하, 최대 3개
   3. 업로드 시 파일명 과 X(업로드 취소) 버튼 노출
   4. 규격(형식/용량) 위반 시 업로드 차단 및 에러 토스트 표시
      1. 지원하지 않는 파일 형식입니다. (JPEG, PNG, PDF만 가능)
      2. 파일 용량이 5MB를 초과했습니다.
      3. 최대 3개까지만 등록 가능합니다.
      4. jpg > jpeg 허용으로 변경
      5. 긴 파일명은 말줄임표 처리
      6. 중복 파일 제외 처리하기. 파일명과 파일 크기가 같을 경우 -> '이미 추가된 파일입니다.' 토스트 노출
      7. 파일명 길이 제한 (확장자 포함 100자 이하) -> '파일명이 너무 깁니다.\n(확장자 포함 100자 이하만 가능)' 토스트 노출
      8. 파일명 허용 문자: 한글, 영문, 숫자, 공백, _, -, (), . 만 허용 -> '사용할 수 없는 문자가 포함되어 있습니다.\n(한글, 영문, 숫자, 공백, _, -, (), .만 가능)' 토스트 노출
6. 등록하기 버튼
   1. 모든 필수 항목 입력 및 유효성 검증 통과 시 활성화
      1. 모든 텍스트 인풋에 값이 입력되었으며 밸리데이션을 통과함
      2. 셀렉트 요소에 셀렉트 값이 있음
      3. url 중복 확인 통과함 (사용 가능 판정)
      4. 증빙 파일 첨부함
   2. 필수 항목 미입력 상태로 버튼 클릭 시 필수 항목 누락 에러 토스트 노출
      1. '필수 항목을 모두 입력해 주세요.'
   3. 유효성 검증 미통과 상태로 버튼 클릭 시 유효성 검증 누락 에러 토스트 노출
      1. '최대 n자까지 입력 가능합니다.'
      2. '허용되지 않은 문자가 포함되어 있습니다.'
   4. 성공 시: 모달 닫힘 및 등록 완료 토스트 노출
      1. '쇼핑몰 등록이 완료되었습니다.'
      2. 신규 연동 요청 생성 및 '승인 대기' 상태로 저장
      3. 쇼핑몰 목록 첫 번째(맨 앞) 위치에 신규 등록된 카드 즉시 추가(낙관적 업데이트 필요할 수 있음)
   5. 실패 시: 모달 유지 등록 실패 토스트 노출
      1. '일시적인 오류로 등록에 실패했습니다.\n잠시 후 다시 시도해주세요.'
