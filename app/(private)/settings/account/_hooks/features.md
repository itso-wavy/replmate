### [회원탈퇴] 버튼

1. 클릭 시 구독 상태별 회원탈퇴 모달 노출

- 유료 / 변경 예정 회원: 모달 내 [구독 해지하기] 클릭 시 구독 관리 페이지로 이동
- 미인증 / 무료 / 해지 대기 회원: 모달 내 [탈퇴하기] 클릭 시 탈퇴 성공 토스트 노출, 계정 삭제 처리, 랜딩 페이지로 이동(약 2초 후??)
  - 성공: toast('회원탈퇴가 완료되었습니다.')
  - 실패: toast('요청에 실패했습니다. 잠시 후 다시 시도해주세요.')

2. 모달

```md
1. 미인증/무료 회원
   회원탈퇴

회원탈퇴시 계정 정보와 이용 데이터가 모두 삭제되며 복구할 수 없습니다.
정말 탈퇴하시겠습니까?

[취소] [탈퇴하기]

2. 해지 대기 회원
   회원탈퇴

회원탈퇴시 남아있는 이용 기간과 데이터는 모두 즉시 소멸되며 복구할 수 없습니다.
정말 탈퇴하시겠습니까?

[취소] [탈퇴하기]

3. 유료/변경 예정 회원
   회원탈퇴

현재 유료 구독이 활성화되어 있어 회원탈퇴가 불가능합니다.
탈퇴를 원하시면 먼저 구독을 해지해 주세요.

[취소] [구독 해지하기]
```
