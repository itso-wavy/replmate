### StoreProductsTable 기능 요구사항

1. 이 테이블은 selectedStoreId에 해당하는 스토어의 상품 목록에 대해서 리스트를 보여준다.
2. 테이블 구성
   1. prop으로 전달되는 maxRows 크기만큼 테이블 한 페이지에 표시된다.
   2. 각 열은 왼편부터 순서대로 이렇게 구성되어 있다.
      1. 체크박스
      2. 상품 번호
      3. 상품명
      4. 가격
      5. 평점
      6. 등록일
   3. 각 열에 해당하는 데이터는 다음과 같은 형태로 되어 있다.
      1. 체크박스:
         1. 체크박스로 해당 상품을 선택/해제 할 수 있다.
      2. 상품 번호:
         1. 예: `PD-12345678`
      3. 상품명:
         1. 예: `이바나 츄르비츠 가다랑어&참치맛`
         2. 한줄로 표시되고 말줄임표 처리. 호버시에 전체 상품명이 표시됨
      4. 가격:
         1. 예: `23,000원`
      5. 평점:
         1. 예: `★ 4.8(625)`, 괄호 안은 평가 개수를 나타냄
      6. 등록일
         1. 예: `2025.12.02`
   4. 테이블 아랫편에 페이지네이션 버튼이 있다.
3. 페이지네이션 버튼 아래에는 추가적인 인디케이터 요소와 저장하기 액션 버튼이 있다.
   1. (왼편)인디케이터: `[쇼핑몰 A] 선택된 상품: 1개` 표시
   2. (오른편)마지막 저장 표시(예: `마지막 저장: 2025년 12월 02일 11:48`)+저장하기 버튼
4. 체크박스 동작
   1. 체크박스를 토글시 서버로 전송되는 값은 없으나, ProductCountIndicator 컴포넌트의 선택 상품 개수와 `[쇼핑몰 A] 선택된 상품: 1개` 인디케이터의 개수가 변화한다. 그러므로 해당 값들은 product 스토어에서 관리해야 한다.
   2. 현재 플랜의 허용 개수를 초과하여 체크 시도 시 선택 차단 및 안내 토스트 노출(`최대 n개까지만 선택 가능합니다.`)
5. [저장하기] 버튼
   1. 클릭 시 체크된 개수가 플랜 한도를 초과하는지 서버 검증
      1. 초과 시: 플랜 업그레이드 유도 팝업 노출(RecommandPlanUpgradeModal)
         1. 팝업 내 [플랜 업그레이드] 클릭 시, 구독 관리 페이지로 이동
      2. 미초과 시: 상품 선택 저장 팝업 노출(ProductSaveConfirmModal)
         1. 팝업 내 [저장] 클릭 시 다음의 작업 수행:
         2. 성공: 저장 완료 토스트 노출(`저장이 완료되었습니다.`)+하단 '마지막 저장' 일시를 현재 시간으로 갱신
         3. 실패: 에러 토스트 노출(`저장에 실패했습니다. 잠시 후 다시 시도해주세요.`)
   2. 저장하지 않고 페이지 이탈 시도 시 이탈 확인 팝업 노출(UnsavedProductChangesModal)
      1. 팝업 내 [확인] 클릭 시, 경고 무시하고 페이지 이탈
      1. 팝업 내 [취소] 클릭 시, 팝업 닫기`
