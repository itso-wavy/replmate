### 기능 요구사항

1. 별칭 수정 기능
   1. 카드에 호버시 쇼핑몰 별칭 오른쪽에 연필 모양 아이콘 버튼이 노출됨.
   2. 연필 버튼 클릭시 쇼핑몰 별칭 영역이 인풋으로 변경되어 기존 등록된 쇼핑몰 별칭을 수정할 수 있게 됨. 인풋에 오토 포커싱
   3. 한글, 영문, 숫자, 하이픈(-), 언더스코어(\_), 괄호, 공백만 입력 가능
   4. 그 외 문자 키 입력 시 화면에 입력되지 않음
   5. 입력 후 포커스 이탈 또는 Enter 키 입력 시 유효성 검증 수행
   6. 최소 글자 미만일 때: 별칭은 2자 이상 입력해주세요. 토스트 노출함. 입력 모드 해제 및 입력 상태 리셋됨
   7. 31자 초과일 때: 더 이상 입력 안 되게 하기
   8. 성공 시 변경된 별칭 즉시 저장 및 입력 모드 해제
2. 연동 상태 인디케이터
   1. 다음 문구 중 하나가 노출됨:
      1. `승인 대기`: 등록 후 관리자 승인이 완료되지 않은 쇼핑몰
      2. `활성`: 관리자 승인이 완료된 쇼핑몰
      3. `반려`: 관리자 승인이 거절된 쇼핑몰(추가문구: 삭제 후 다시 등록해 주세요.)(이건 강조해서 보여주기)
      4. `비활성화 예정`: 플랜 다운그레이드 시 유지 대상으로 선택되지 않은 쇼핑몰(이건 강조해서 보여주기)
      5. `비활성`(이건 강조해서 보여주기)
3. More 버튼
   1. 클릭시 드롭다운 메뉴 노출됨
   2. 내부 메뉴로 현재는 '연동 해제'만 존재
   3. '연동 해제' 클릭시 연동 해제 모달 노출됨
4. 바로가기 버튼 그룹
   1. 클릭 시 해당 기능 페이지로 이동
   2. 이동 시 선택된 쇼핑몰 ID를 파라미터로 전달하여, 도착 페이지의 필터가 해당 쇼핑몰로 자동 선택되도록 처리
